# Design System Components

This folder contains 15 React component files for the design system.

## Installation

1. Copy the entire `src/` folder to your project
2. Import components as needed:

```tsx
import { Button } from './components/design-system/Button';
import { Input } from './components/design-system/Input';
```

## Components Included

- Button (Button.tsx)
- Input (Input.tsx)
- Card (Card.tsx)
- Badge (Badge.tsx)
- Alert (Alert.tsx)
- Avatar (Avatar.tsx)
- ProgressBar (ProgressBar.tsx)
- Spinner (Spinner.tsx)
- IconButton (IconButton.tsx)
- Divider (Divider.tsx)
- Checkbox (Checkbox.tsx)
- Switch (Switch.tsx)
- Select (Select.tsx)
- Textarea (Textarea.tsx)
- Index (Barrel Export) (index.ts)

## Dependencies

- React 18.3.1+
- lucide-react (for icons)
- Tailwind CSS v4

For full documentation, visit the live design system documentation page.
